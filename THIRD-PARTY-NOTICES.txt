Dictum: third-party notices
===========================

Dictum is Copyright (c) 2026 Kynni Pty Ltd, under the MIT licence (https://github.com/kynniau/dictum/blob/main/LICENSE).

This file gives the licence notice of every third-party component that ships in the folder that holds Dictum.exe: the
speech model, the .NET runtime, and each library or native runtime that arrives as a NuGet package.

How to read it. Each package entry begins with a "Package: <id> <version>" line, then the files the package puts in
that folder ("Ships as"), its licence, and the licence text. Where a package carries its own licence file, that file
is reproduced unchanged. Where a package names only a licence identifier (MIT), the standard text for that identifier
follows, with the copyright line exactly as the package's .nuspec gives it; where the .nuspec gives none, the entry
says so. "(nuspec)" marks a value quoted from the package's .nuspec. "Copyright (upstream licence)" gives, beside it,
the copyright line of the LICENSE file in the project's own source repository, read 23/10/2026: Avalonia at tag 11.3.22,
LLamaSharp at v0.27.0, NAudio at v3.1.0, and llama.cpp on its master branch. The versions are those this build restored.
Annexes A to C reproduce, unchanged except for line endings, the notices that Microsoft's and the .NET Foundation's
packages carry for the material inside them.

Not covered here: the Microsoft Visual C++ runtime. A default build does not carry it (the installer offers
Microsoft's download, and the Microsoft Store package declares Microsoft's framework package instead). A build made
with scripts\publish.ps1 -VcRuntimeDir carries Microsoft's runtime DLLs too; this file would then need the notice that
Microsoft's licence for them asks for.

Contents

  1. The speech model
  2. Microsoft .NET runtime and Windows SDK projection
  3. Speech recognition: Whisper.net and its native whisper.cpp runtimes
  4. AI clean-up: LLamaSharp and its native llama.cpp backends

  7. Support libraries
  Annex A. Notices for the material inside .NET
  Annex B. Notices for the material inside SkiaSharp and HarfBuzzSharp
  Annex C. Notices for the material inside CommunityToolkit.HighPerformance
