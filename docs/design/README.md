# Dictum design reference

These are the approved UI mockups (15/10/2026), exported from the design canvas. Each
`*.dc.html` is a self-contained HTML artboard; open it in a browser or read the markup for
exact colours, sizes, spacing and copy. `canvas.json` lists the boards.

| File | Shows |
|---|---|
| Main.dc.html | Name, mark at every size and state, colour tokens, type scale, shape and motion rules |
| Flyout.dc.html | The tray flyout: status, On/Off, Light/Full, model and mic pickers, toggles, actions |
| Pill.dc.html | The six pill states |
| Indicators.dc.html | Screen-edge glow, the orb, the pill and the tray icon on a desktop |
| Calibrate.dc.html | Calibration window |
| FixLast.dc.html | Fix last dictation window |

Tokens: Ink #0B1220, Accent #2457E6, Recording #E5484D, Working #F5A524, Done #30A46C,
Surface #FFFFFF on #F4F6FA (light) and #141C2B on #0B1220 (dark), Muted text #64748B.
Type: Segoe UI Variable on Windows (system font; on macOS the system font). Radius 8 on
controls, 12 on cards, 22 on the pill. Motion: the red dot breathes at 1.2 s, everything
else is a 150 ms fade, both off under reduced motion.
