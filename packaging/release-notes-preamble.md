**Before you install the direct download.** It needs the Microsoft Visual C++ Redistributable (x64), version 14.51 or later. On a PC without it, speech recognition and AI clean-up cannot load and the tray shows "model error". `Dictum-Setup-<version>.exe` checks before it installs anything and offers Microsoft's download, https://aka.ms/vc14/vc_redist.x64.exe (installing it needs administrator rights). The portable zip has no installer: install the runtime first. The test MSIX, for testers (docs/TESTING-MSIX.md), needs Microsoft's Visual C++ framework package, Microsoft.VCLibs.140.00.UWPDesktop 14.0.33728.0 or later, installed first.

**The base.en speech model is included.** The installer, the zip and the test MSIX each carry `models\ggml-base.en.bin` beside `Dictum.exe` (the Whisper base.en model, MIT licence). Its notice, and those of every other third-party component, are in `THIRD-PARTY-NOTICES.txt`. Larger models are optional downloads from Settings > Models.
