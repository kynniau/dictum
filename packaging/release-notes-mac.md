**PROPOSED (not yet approved by the owner): Dictum for macOS (beta).** `Dictum-<version>-osx-arm64.zip` is for Apple Silicon Macs on macOS 15 or later; Intel Macs are not supported. It is signed and notarised when it was built with the owner's Developer ID certificate; a build made without one is signed ad-hoc and macOS will refuse to open it until you allow it in System Settings > Privacy & Security. Check the zip against `SHA256SUMS-mac.txt`. Unzip it, move `Dictum.app` to Applications and open it. Two things to expect the first time: macOS asks for **Microphone** access and for **Accessibility** access (to see your hotkey and to paste into other apps); and if you turn on launch at login, macOS asks you to approve it in **System Settings > General > Login Items**. The base.en speech model is inside the app.

This file is the notes of the macOS pre-release only (`release-mac` in .github/workflows/ci.yml, on a `mac-v<version>` tag); the Windows release notes are packaging/release-notes-preamble.md.
