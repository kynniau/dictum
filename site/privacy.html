Privacy policy

Dictum by Kynni. Last updated 23/10/2026.

This policy covers the Dictum desktop app for Windows PCs, whether you install it from the Microsoft Store or as the direct download, and this website, dictum.kynni.au. A Mac version is coming soon and will be covered by this policy when it is released. Dictum is made by Kynni Pty Ltd (“we”).

The short version

  • We collect nothing. Dictum has no account, no analytics, no telemetry and no crash reporting. We never receive your audio or your text.
  • Your speech is turned into text on your PC, unless you turn on cloud speech, and the text is tidied on your PC.
  • Dictum goes online only when you ask it to: to download a model, to check for updates in the direct-download version, or, if you switch it on, to send text to a cloud clean-up service, or your voice to a cloud speech service, or a server you choose.

What we collect

Nothing. Dictum sends us no data: no usage statistics, no crash reports, no device or user identifiers. We only know what you choose to tell us, for example if you email us. The Email support, Report a problem and Send feedback buttons in Settings open a new email in your own mail program with Dictum’s version and the models in use filled in; Send feedback also includes your Windows build number. You can change or delete any of it before you send it.

What Dictum uses on your PC

Microphone

Dictum opens the microphone only while you are dictating (holding the hotkey, or in hands-free mode) or recording a calibration sentence, and closes it afterwards, so the Windows microphone indicator is off the rest of the time. The audio is kept in memory while it is turned into text, then discarded. It is never written to disk, except the calibration recordings you make on purpose (below). With cloud speech on, the recording is sent to the service you chose and then discarded here.

Your words

Transcripts are not stored. The last dictation is kept in memory so you can use Fix last dictation, and is gone when Dictum quits. Logs never contain what you said unless you turn on the log_transcripts setting.

Keyboard

Dictum watches for its hotkeys and the Esc key only. It does not record, store or send your keystrokes. When you choose a hotkey in Settings, the capture box shows the key you press, and only the name of the key you choose is saved.

Clipboard

To paste, Dictum puts the text on the clipboard and presses Ctrl+V for you. By default the text stays on the clipboard so you can paste it again; turn on insert.restore_clipboard to put your previous clipboard back (text only). Dictum marks the text so that Windows keeps it out of clipboard history (Win+V) and does not sync it to your other devices. Clipboard managers that ignore that marker can still see it. You can allow clipboard history with insert.clipboard_history, or set insert.method to type so the clipboard isn’t used at all.

Calibration recordings

If you use Calibrate my voice, you record ten sentences. Those ten WAV files stay on your PC so you can re-run the test later, are never uploaded, and are used only by the calibration window. Delete them any time with Delete recordings.

What Dictum keeps on your PC, and where

%APPDATA%\Dictum

  • settings.json: your settings.
  • dictionary.txt and corrections.txt: your names, terms and fixes, if you add any.
  • profanity.txt: only if you add your own word list.
  • .env: an API key, only if you add one for cloud clean-up or cloud speech. (The direct download also reads a .env you place beside Dictum.exe.)

%LOCALAPPDATA%\Dictum

  • models: the speech and clean-up models you downloaded.
  • logs: one file per day, the newest 14 kept.
  • calibration: your calibration recordings, if you made any.
  • verified-models.json: which model files passed the integrity check.

In the Microsoft Store version, Windows keeps these files in Dictum’s private app folder under %LOCALAPPDATA%\Packages\Kynni.Dictum_43s584kx66f64\LocalCache and deletes them when you uninstall Dictum. Settings → Storage in Dictum shows the exact folders on your PC.

These are ordinary files, protected by your Windows account like the rest of your documents. You can open, read, edit and delete them. If you turn on launch at login, the direct download adds a Run entry for Dictum under your Windows account’s registry settings, and the Store version uses Windows’ own startup-app setting.

The logs record timings, character counts, device names, which models and runtimes loaded, which clean-up step ran and why, warnings and errors, and how many dictionary words and corrections were loaded (never the words themselves). Any API key that would appear in a log is replaced with [redacted].

When Dictum connects to the internet

Only in these cases, and only to these hosts. Nothing else: no telemetry, analytics or crash reports.

Model downloads: huggingface.co

Only when you choose a model to download (in the first-run picker, the model menus, the missing-model prompt or on the command line). Dictum requests the model file and sends nothing about you or what you say. Hugging Face may hand the download over to its content network; on 15/10/2026 that was us.aws.cdn.hf.co, and the host can vary by region. Every file is checked against a SHA-256 fingerprint before Dictum uses it.

Cloud clean-up: api.anthropic.com (off by default)

Only if you set the clean-up provider to Anthropic and add your own API key. After each dictation Dictum then sends the text of that dictation, its clean-up instructions and your dictionary terms to Anthropic, with your key. Anthropic handles that data under its own terms and privacy policy. If you also set a custom address for this provider, the same data goes to that address instead. This is an advanced option: Dictum does not validate or certify how that service stores, protects or uses the text it receives. Check its terms before dictating anything sensitive.

OpenAI-compatible service (off by default)

Only if you choose a preset or enter an address yourself. The presets point at api.openai.com (OpenAI) or generativelanguage.googleapis.com (Google Gemini); a custom address goes wherever you enter. After each dictation Dictum sends that service the text of the dictation, its clean-up instructions and your dictionary terms, with your key. That service handles the data under its own terms. If the server runs on your PC, for example Ollama at localhost, nothing leaves your PC unless that server itself forwards to a cloud service, which Dictum cannot see: Ollama can serve its cloud models once you sign in to it. This is an advanced option: Dictum does not validate or certify how that service stores, protects or uses the text it receives. Check its terms before dictating anything sensitive.

Cloud speech (off by default)

Only if you switch on cloud speech in Settings > Models, agree to the service in its own consent step and, for OpenAI, Azure OpenAI or Groq, add your own API key (a server you name may need none). After each dictation (each part, in hands-free) Dictum then sends that dictation’s recording, as a WAV file, to the service you chose, together with the words in your personal dictionary as a hint and, in hands-free, the closing words of the part before. The service is OpenAI (api.openai.com), Azure OpenAI ({resource}.openai.azure.com, your own resource), Groq (api.groq.com) or a custom https:// address you enter. That service handles your voice under its own terms. This is an advanced option: Dictum cannot validate or certify how that service stores, protects or uses your voice. Check its terms before dictating anything sensitive.

This website: dictum.kynni.au

Only when you open the privacy policy, Dictum in plain words or the full guide from Settings, or click Check for updates in the direct-download version, which reads one small file and sends nothing about you; the Store build is updated by the Store.

Offline only

With the offline_only setting turned on, Dictum never connects to anything outside your PC: downloads, cloud clean-up, cloud speech and servers that aren’t on your PC are all refused. A clean-up or speech server running on your own PC still works. You can copy model files in instead of downloading them.

What any connection reveals

Like any internet connection, each of these reveals your IP address to the host you connect to. Hugging Face, Anthropic, OpenAI, Azure OpenAI, Groq, Google Gemini and any server you name handle that under their own policies. Model downloads and requests to Anthropic, OpenAI, Azure OpenAI, Groq and Google Gemini use HTTPS. A server you name yourself uses the address you give it, so use an https:// address for anything that isn’t on your own PC.

If you install from the Microsoft Store

Microsoft handles the download, licence and updates under the Microsoft Privacy Statement. Microsoft gives app publishers summary reports in Partner Center, such as how many people installed an app and in which markets, and reports of crashes and hangs taken from Windows diagnostic data (for example the app version, device model and Windows version where a crash happened). Dictum itself sends none of this. We use these reports only to find and fix problems.

This website

dictum.kynni.au uses no cookies, no analytics, no tracking and no scripts. Our web host, Vercel, receives the standard information any website needs to deliver a page, such as your IP address and browser type. Links to GitHub, the Microsoft Store and the Kynni website take you to those sites, which have their own policies.

Deleting everything

In Dictum, open Settings → Storage. You can delete calibration recordings, logs or individual models, or choose Remove Dictum completely. That deletes everything Dictum has stored (models, recordings, logs, settings, dictionary, corrections and .env), its Start menu shortcut and start-at-login entry, and the app itself. You see the full list of files and their sizes first and type DELETE to confirm; there is no undo. In the Microsoft Store version it deletes the data, then opens Windows Settings so you can uninstall the app.

By hand: search Start for “Add or remove programs”, find Dictum and choose Uninstall. For the direct download, then delete the folders %APPDATA%\Dictum and %LOCALAPPDATA%\Dictum. Uninstalling the Microsoft Store version also deletes the files Windows kept in Dictum’s private app folder.

Changes to this policy

If a version of Dictum changes what it stores or sends, we will update this page and its date before that version is released, and say so in the release notes.
