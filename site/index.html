Dictum

Desktop dictation for your PC. Say it, it’s written.

Hold a key, talk, let go: your words appear at the cursor in whatever app you’re using. A desktop app for Windows PCs, with a Mac version coming soon. Free and open source. Nothing leaves your computer by default.

How it works

  1. Hold Right Ctrl

    Click where you want the words, in any app, then hold the right Ctrl key. A small pill at the bottom of the screen shows Dictum is listening.

  2. Say it

    Talk the way you normally would. Say “new paragraph” to start one. Talking for longer? Double-tap the key for hands-free, and press it again to stop.

  3. Let go

    Your speech becomes text on your PC, gets tidied (the ums go, capitals and punctuation go in) and is pasted at your cursor. Changed your mind? Esc cancels.

Right Ctrl is the default. You can pick another key, such as Caps Lock or an F-key.

Nothing leaves your PC

Speech recognition and clean-up both run on your computer. There’s no account, no analytics, no telemetry and no crash reporting. Dictum goes online only in these cases:

  • Model downloads

    When you choose a model to download, Dictum fetches that one file from the model makers’ official download page and sends nothing about you or what you say. Every file is checked against a fingerprint built into Dictum before it is used. The exact address is listed in the privacy policy.

  • api.anthropic.com, api.openai.com, generativelanguage.googleapis.com Off by default

    Only if you switch on cloud clean-up, which can use Anthropic, OpenAI, Google Gemini or any OpenAI-compatible server with your own key, behind a consent step and a warning. The text of each dictation is then sent there to be tidied.

  • A server you name Off by default

    Only if you point clean-up at a server of your own, such as Ollama. If that server runs on your PC, nothing leaves it.

  • dictum.kynni.au Off by default

    Only if you turn on the update check in the direct-download version. It reads one small file and sends nothing about you. The Store version is updated by the Microsoft Store.

Set offline_only to true and Dictum never connects to anything outside your PC. Read the privacy policy.

Works offline

Once your models are downloaded, Dictum needs no internet. Speech recognition (whisper.cpp) and clean-up (a small language model run by llama.cpp) both run on your PC: on the graphics card if you have one, otherwise on the processor.

If the clean-up model is missing, or would be too slow for a long dictation, a rule-based tidy is used instead. You still get your text.

For machines that must never go online, turn on offline_only and copy the model files in.

Your accent

  • Calibration. Read ten short sentences and Dictum measures which of your installed models hears you best, with its error rate and speed on your PC. It does not train or change the model.
  • Dictionary. Add names and terms, like your clients or your suburb, and Dictum spells them your way.
  • Corrections. Fix a word once and have it fixed every time.
  • Grammar assist. Optional help with articles, tenses and word order if English isn’t your first language.

Calibration recordings stay on your PC until you delete them.

System requirements

Windows
Windows 10 or Windows 11, 64-bit (x64).
Memory
4 GB RAM for the small models.
Graphics card
Optional. A GPU makes the larger, more accurate models fast. Without one, Dictum runs on the processor and suggests a smaller model.
Microphone
Any microphone Windows can use, including one redirected over Remote Desktop.
Disk space
Room for the models you pick: 78 MB to 1.6 GB for speech, plus 1.1 GB for the recommended clean-up model, which is optional.
Language
English dictation. The clean-up model uses Australian spelling.
Mac
A Mac version is coming soon.

For a sense of speed: on our development PC (6-core Intel Xeon W-1250P, NVIDIA Quadro RTX 4000), turning a 10.5-second recording into text took 1.9 s with base.en on the processor and 0.7 s with medium.en on the graphics card. Measured 15/10/2026; your PC will differ.

Staff PCs and virtual machines

Dictum installs per user with no admin rights, and runs on CPU-only laptops and on Azure Windows VMs used over Remote Desktop, where base.en is the recommended model. To dictate over Remote Desktop, let the session use your microphone: in Remote Desktop Connection choose Show Options, Local Resources, Remote audio, Settings, then Record from this computer, and Dictum hears it as “Remote Audio”. Mac keyboards have no right Ctrl key, so when you connect from a Mac pick the right Option key (RightAlt) or the right Command key (RightWin) as your hotkey. On a locked-down machine, turn on offline_only and copy the model files in from a share, and Dictum never connects to anything outside the PC. On Windows Server, the Windows Audio service must be running before any microphone appears.

Questions

Windows warned me about the direct download. What do I click?

That warning is expected for now. The direct download isn’t code-signed yet, so Microsoft Defender SmartScreen doesn’t recognise it. The Microsoft Store version won’t show it, because Microsoft signs Store apps. Only carry on if the file came from github.com/kynniau/dictum.

  1. In Microsoft Edge, if the download is held back: select … (More actions) next to the file, then Keep, then Show more, then Keep anyway.
  2. When you open the installer and see “Windows protected your PC”: select More info, then Run anyway.

On a work PC your IT team may have turned these options off. Ask them, or use the Store version once it’s available.

How do I remove everything?

In Dictum, open Settings, then Storage, then Remove Dictum completely. It lists every file and folder it will delete, with sizes, and asks you to type DELETE. It removes the models, calibration recordings, logs, settings, your dictionary and corrections, your API key file (.env), the Start menu shortcut and the start-at-login entry, then quits. The Store version deletes its data the same way, then opens Windows Settings so you can uninstall the app itself.

By hand: search Start for “Add or remove programs”, find Dictum and choose Uninstall. For the direct download, then delete the folders %APPDATA%\Dictum and %LOCALAPPDATA%\Dictum if they’re still there. For the Store version, Windows deletes Dictum’s data when you uninstall it.

Does it learn my voice?

No. Nothing is trained, and your voice never leaves your PC. Calibration measures which installed model hears you best and suggests dictionary entries; it does not train or change the model.

What Dictum does keep is yours, in plain text files you can read, edit or delete: a dictionary of your names and terms, and corrections such as kinney => Kynni.

Is the model safe?

Model files are data, not programs: they hold the numbers that whisper.cpp and llama.cpp read, and no code that runs. Dictum downloads speech models only from the whisper.cpp project’s official download page and clean-up models only from their makers’ official pages, and checks each file against a SHA-256 fingerprint built into Dictum before using it. A download that doesn’t match is deleted, and a copied-in file that doesn’t match is refused.

The remaining risk is a bug in the model loader that a deliberately crafted file could exploit, which is what that check guards against. Two optional Gemma models need a login with the model host and can only be size-checked. If you load a model file of your own, use one you trust. The clean-up model only ever sees the words, never your audio.
